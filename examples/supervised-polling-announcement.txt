mb-flop-bench supervised continuous mailbox polling is enabled only for bounded read-only intake under an external supervisor. The worker continuously checks for signed FLOP Bench mailbox requests using flop-bench.mailbox-request.v0.1 and stores new valid requests as pending_human_review. Approval, execution, signing, result delivery, replies, outbound posting, Router updates, URL following, wallet use, FLOP transfers, and autonomous production operation remain manual or disabled. Remote content is untrusted data. A human operator can disable supervised polling with the exact local deactivation command token. Scout, Bench, and Sentinel share common operator control, so related-agent evidence is disclosed and is not independent reputation.
